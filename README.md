# ⚡ Power Trading Price Forecasting

## 📌 Project Overview
This project predicts electricity market price (MCP) using machine learning.

## 🚀 Features
- Uses market, weather, and historical data
- Lag & rolling feature engineering
- Random Forest model (~4% MAPE)
- Streamlit web application

## 🧠 Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn, XGBoost
- Streamlit

## ▶️ Run Project
```bash
streamlit run app.py
